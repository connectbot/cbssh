# preferPasswordAuth

[jvm]\
var [preferPasswordAuth](prefer-password-auth.md): [Boolean](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-boolean/index.html)

When true, prefer `password` over `keyboard-interactive` when both are available. By default, `keyboard-interactive` is preferred.
