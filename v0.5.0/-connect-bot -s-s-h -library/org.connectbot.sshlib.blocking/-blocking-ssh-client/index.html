BlockingSshClient

class BlockingSshClient(source)

Blocking wrapper for SshClient for Java compatibility.

This class wraps the async SshClient with blocking calls using runBlocking. For Kotlin code, prefer using SshClient directly with coroutines.

Usage from Java:

BlockingSshClient client = new BlockingSshClient("example.com", 22, myHostKeyVerifier);
try {
    client.connect();
    client.authenticatePassword("user", "password");
    SshSession session = client.openSession();
    // ...
    session.close();
    client.disconnect();
} catch (SshException e) {
    // handle connection or auth failure
}
